# Release Contents

This folder is a clean GitHub source/export copy for ModTheSpire2 0.4.0.

It excludes local runtime data, generated build outputs, uploader binaries, Steam cache files, and old experimental package folders.

The uploadable Workshop content is under:

```text
dist/WorkshopUpload/ModTheSpire2Content-Clean
```

The Workshop metadata template is under:

```text
ModUploader-win-x64/template/workshop.json
```
